# Security Policy

## Reporting a vulnerability

If you find a security issue in the HoN Reborn Mod Manager, the mods, or the catalog, please report it privately through GitHub. Open the Security tab of this repository and use Report a vulnerability. Reports go straight to the maintainer and stay private until a fix is out.

Please do not open public issues for security problems.

## Scope

This covers the mod manager application, the honmod files served by the catalog, and the catalog itself. The game Heroes of Newerth Reborn and the Juvio launcher are not part of this project, so issues with them should go to their own maintainers.

## Supported versions

Only the latest released version of the mod manager is supported. The app updates itself, so staying current is automatic.
